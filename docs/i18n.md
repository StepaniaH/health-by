# Languages

The web interface supports English and Simplified Chinese. Use the header language
selector or `?lang=en` / `?lang=zh`. Selection follows this order: URL parameter,
saved browser preference, browser language, Chinese fallback. Storage can be blocked;
the URL selector still works.

API requests use `Accept-Language`; a `lang` query parameter takes precedence. Responses
include `Content-Language`. CLI output uses `health-by --lang en ...` or
`HEALTH_BY_LANG=en`. Stored measurements, exports, user text and model responses retain
their original content. AI instructions are not translated.

To clear data, type `DELETE ALL DATA` in either language. The API uses the same literal
value in its `confirm` field.

## Catalogs

Both runtimes use `health_by/locales/zh.json` and `en.json`. Keys are scoped by module
and function. Named parameters form complete templates; optional sentences use separate
keys. Counted messages use complete `.one` / `.other` variants. `plurals.json` lists the count parameters in suffix order; independent counts have one suffix each. Explicit request-count messages use a `count` parameter. Formatting helpers
produce numbers; catalog entries contain units and language-specific word order.

Numbers use comma grouping in both languages. The heading uses a localized date and
weekday. Table dates and date axes use `YYYY-MM-DD`; clock times use 24-hour notation.

After editing a catalog:

```sh
npm ci
python scripts/build_i18n.py
python scripts/check_i18n.py
python scripts/check_web_refs.py
python -m pytest
```

Node.js and Acorn are development tools. The browser has no package dependencies or
build step. The generated `web/js/i18n-messages.js` file is committed and checked for
parity with the JSON catalogs.

## Source checks

The checker parses Python and JavaScript syntax, and checks HTML translation markers.
It rejects untranslated Chinese UI literals, locale literals outside i18n modules,
and conditional fragments inside JavaScript template strings. Comments and developer
docstrings are excluded. CLI command help uses explicit translation keys.

| Exemption | Scope |
| --- | --- |
| `health_by/ai/prompt.py` | Model instructions; translation changes model behavior. |
| SQL comments inside `health_by/db.py:MIGRATIONS` | Developer annotations in executable schema source. |
| `health_by/ai/schema.py:MODEL_WEEKDAYS` | Fixed weekday labels in the model input protocol. |
| `health_by/ai/validation.py` aliases, match patterns and prohibited phrases | Recognition of model text; output warnings use catalog keys. |
| `health_by/i18n.py`, `web/js/i18n.js` | Locale selection and rendering. |
| `web/js/i18n-messages.js` | Generated catalog, verified against JSON. |
| `health·by`, `Health By`, language names | Proper names and language selector labels. |
| `ms`, `bpm`, `kg`, `°C`, `%`, `HRV`, `SpO₂` | Standard symbols and abbreviations. |
| Protocol identifiers and `DELETE ALL DATA` | Machine-readable values, retained in either language. |
